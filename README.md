# 基于年报文本挖掘的企业数字化转型测度研究

> **NLP 测度构建方法 · 预演毕业论文（模拟稿）** ｜ 论文 + 可复现代码 + 测度面板 + 数据说明 全套材料

本项目依据"NLP 测度构建方法"课程作业要求完成，研究方向为**基于上市公司年报 MD&A 文本的企业数字化转型测度**：以标准五步流水线（文本获取 → 文本预处理 → 词典构建 → 测度计算 → 信效度检验）从非结构化文本构建可复现测度，并检验其与企业绩效（ROA）、研发投入的关系。


预期输出（与论文完全一致）：

```text
[Step1 文本获取] 共定位 180 篇企业-年份文档
[Step2 文本预处理] 清洗完成，语料总字数 214546，均值 1192 字/篇
[Step3 词典构建] 5 个类别、89 个词项
[Step4 测度计算] DT1=ln(1+词频), DT2=每万字词频, DT3=类别熵
[Step5 检验分析] Cronbach α=0.732 | 折半 SB=0.730 | 聚合 r=0.566 | 区分 r=0.051 | 备择 r=0.888
    模型1：ROA  R2=0.241 | 模型2：研发强度RD  R2=0.763 | 模型3：备择测度  R2=0.168
```

## 核心结果速览

| 维度 | 结果 |
| --- | --- |
| 信度 | Cronbach's α = 0.732，Spearman-Brown 折半信度 = 0.730 |
| 聚合效度 | corr(DT1, 无形资产占比) = 0.566 |
| 区分效度 | corr(DT1, 泛管理热词密度) = 0.051（构念独立，非修辞热度） |
| 备择测度 | corr(DT1, DT2) = 0.888 |
| 经济后果 | DT 每提高 1σ：ROA +0.58pp（t=6.23\*\*\*），研发强度 +0.80pp（t=15.18\*\*\*） |

## 研究步骤（六步，与五步流水线对应）

## 重要说明
