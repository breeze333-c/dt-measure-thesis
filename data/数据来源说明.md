# 数据来源说明（一页版）

本文为"NLP 测度构建方法"课程预演毕业论文（方法学演示稿）。各文件的来源与处理步骤逐一说明如下。

## 1. 语料：`data/corpus/{股票代码}_{年份}.txt`（180 篇）

- **真实研究的获取路径**：巨潮资讯网（www.cninfo.com.cn）→ 检索样本公司年度报告 → 下载 PDF → 提取"管理层讨论与分析（MD&A）"章节文本（可用 pdfplumber/PyMuPDF 按目录定位章节）→ 按 `{6位股票代码}_{4位年份}.txt` 命名存入 `data/corpus/`。
- **本文的实际来源**：因课程周期与版权限制，语料由 `code/simulate_corpus.py` **程序化生成**（随机种子 2026，可精确复现）。生成器按真实 MD&A 的文本结构组织：总述段 + 经营讨论段落 + 展望段落；企业潜在数字化转型强度 d_it 决定数字技术语句的泊松到达率（λ=5+60·d），语句跨词典类别共现；泛管理热词按转型强度等比例投放（保证与构念独立）；同步生成研发强度、ROA、无形资产占比等财务变量，使语料内部存在真实可被测度捕捉的结构。
- **处理步骤**：见 `pipeline.py` 的 `step2_preprocess()`——全半角归一、小写化、空白与版式噪声剔除、字数统计。清洗后语料 214,546 字，篇均 1,192 字。

## 2. 词典：`code/dictionary/digital_dict.txt`

- **来源**：以吴非等（2021，《管理世界》）五类关键词表为基础底表，人工增补近年高频技术词（数据中台、数字孪生、边缘计算等），剔除同形异义泛化词。
- **处理步骤**：词项经人工逐条审核（保留明确指向数字技术实际运用的词项），最终 5 类 89 词；匹配用最长优先正则交替模式（`pipeline.py` 的 `step3_dictionary()`）。

## 3. 财务元数据：`data/financials_raw.csv`、`data/firms.csv`

- **真实研究的获取路径**：CSMAR / Wind / CSMAR 财务数据库下载 ROA、研发投入、无形资产、总资产、资产负债率、成立年份、产权性质，按"股票代码-年份"匹配。
- **本文的实际来源**：与语料同源生成（`simulate_corpus.py`），生成式为 ROA=0.018+0.055·d−0.02·(Lev−0.42)+ε、RD=0.018+0.09·d+0.006·(Size−22.2)+ε，即财务变量与潜在转型强度存在真实关系，供回归检验捕捉。

## 4. 测度结果面板：`data/panel.csv`

- **来源**：由 `pipeline.py` Step4 计算：五类词频 → DT1=ln(1+词频)、DT2=每万字词频、DT3=类别熵，并与财务元数据按"代码-年份"合并。
- **处理步骤**：`step4_measure()` + `merge_panel()`，输出 180 行 × 22 列的企业-年份面板（含公司名、行业、产权性质、词频明细、三类测度与财务变量）。

## 5. 结果文件：`results/*.csv` 与 `results/summary.md`

- **来源**：`pipeline.py` Step5（`step5_analyze()`）自动生成，含信效度检验、描述性统计、相关性矩阵、三组 OLS 回归（含年度与行业固定效应）。论文正文表 3–表 6 的全部数字与之一一对应，未做任何人工修改。

## 6. 声明

- 本文全部结果均由开源代码对上述数据自动运行产生，随机过程均固定种子，**任何人可一键复现**：`python code/simulate_corpus.py && python code/pipeline.py`。
- 模拟语料仅用于方法学预演示范；接入真实年报语料与真实财务数据时，仅需替换 `data/corpus/` 与 `financials_raw.csv`，代码零改动。
